# Data

Raw CSV files are intentionally not distributed in this repository because their original redistribution license has not been verified.

To run the experiments, place the required CSV files in this directory or another local directory and update `data.locations` in your JSON config.

## Expected format

- Index column: `Date`
- Default encoding: CP949 (configurable)
- Target column contains: `Cyanocell`
- Input variables include water temperature, chlorophyll-a, total nitrogen/phosphorus, water level, discharge, precipitation, air temperature and forecast temperature.

Document the original source, download date, license and preprocessing steps before sharing a dataset.
